# Counter App

A simple and clean counter web application built with HTML, CSS, and JavaScript.

## Features

- Increment counter with + button
- Decrement counter with - button
- Color changes based on counter value (red when 0, blue otherwise)
- Smooth hover effects
- Responsive design

## Demo

Just open `index.html` in your browser.

## How It Works

- Click the green **+** button to increase the count
- Click the red **-** button to decrease the count
- Counter cannot go below 0
- Color changes from red to blue when count is not zero

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
